## Salient Features

- Promotes green economy by using solar-powered charkhas.
- A cluster includes 200-2042 beneficiaries.
- Beneficiaries: Individuals, promoter agencies, or existing KVIs setting up solar charkha clusters.
- Implementing Authority: Khadi and Village Industries Commission (KVIC).
